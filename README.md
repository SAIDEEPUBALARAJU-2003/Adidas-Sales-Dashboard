# Power BI Project – Data Analysis Dashboard

##  Project Overview
This project demonstrates data analysis and interactive dashboard creation using **Power BI**.  
The goal is to transform raw data into meaningful insights through visualizations, KPIs, and reports.

##  Objectives
- Analyze structured data efficiently
- Identify key trends and patterns
- Build interactive and user-friendly dashboards
- Support data-driven decision making

##  Tools & Technologies
- Power BI
- Power Query
- DAX
- Excel / CSV (Data Source)

##  Key Features
- Interactive dashboards
- KPI indicators
- Filters and slicers for dynamic analysis
- Trend and comparison analysis

##  Insights Generated
- Performance trends over time
- Category-wise and metric-wise analysis
- Key business indicators visualization
